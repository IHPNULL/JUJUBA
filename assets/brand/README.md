# Arte-fonte

Originais em 1024×1024 do ícone do app (a jujuba com o quadrado rosa
arredondado). Não são carregados pelo app: servem de fonte para gerar os
arquivos de `assets/` quando o ícone precisar ser refeito ou reexportado.

| Arquivo | Uso |
|---|---|
| `icone-app-1024.png` | Original com transparência — use este como fonte. |
| `icone-app-1024.jpg` | Mesma arte em JPEG, sem transparência e com perda. |

O ícone que aparece DENTRO do app (cabeçalho da tela Início) é outro
arquivo: `assets/jujuba-icon.jpeg`, a jujuba sem a moldura quadrada.
